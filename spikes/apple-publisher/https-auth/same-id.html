Apple Music same-ID mutation proof

This isolated test creates one clearly named disposable playlist and preserves its ID through four separately initiated operations.

  1. Create A–B–C
  2. Append D → A–B–C–D
  3. Remove B → A–C–D
  4. Reorder → D–C–A

Each write is fenced in browser storage before Apple is called and completes only after full ordered readback. Existing playlists are never changed or deleted.
